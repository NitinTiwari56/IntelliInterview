# InterviewService - AI-Driven Placement Interview Platform

`InterviewService` is a core microservice of the **Interview IQ** placement preparation platform. It manages real-time AI-powered Technical and HR mock interviews via streaming WebSocket and REST APIs, evaluates candidate answers using structured rubrics, tracks per-session state, persists interview records, and emits completion events for cross-module performance analytics and roadmap generation.

## 🔌 WebSocket Protocol (`/ws/interview`)

### 1. Client to Server Messages

#### Start Session:
```json
{
  "type": "START_SESSION",
  "studentId": 101,
  "data": {
    "interviewType": "TECHNICAL",
    "inputMode": "TEXT",
    "targetRole": "Java Backend Developer",
    "resumeText": "...",
    "resumeSkills": ["Java", "Spring Boot", "MySQL", "Docker"],
    "maxQuestions": 5
  }
}
```

#### Submit Answer:
```json
{
  "type": "ANSWER",
  "sessionId": "9c49ae9f-5b16-4e3a-8ed5-796eb3fde04d",
  "content": "HashMap uses an array of buckets. Key collisions are handled via linked list chaining..."
}
```

#### Reconnect:
```json
{
  "type": "RECONNECT",
  "sessionId": "9c49ae9f-5b16-4e3a-8ed5-796eb3fde04d"
}
```

#### End Early:
```json
{
  "type": "END_SESSION",
  "sessionId": "9c49ae9f-5b16-4e3a-8ed5-796eb3fde04d"
}
```

### 2. Server to Client Messages

- `SESSION_STARTED`: Confirms session creation and details.
- `QUESTION_CHUNK`: Streamed token-by-token question content.
- `QUESTION_COMPLETE`: Full question text when generation finishes.
- `EVALUATION`: Rubric score, feedback, strengths, and improvements for the submitted answer.
- `SESSION_SUMMARY`: Final score, total questions, consolidated feedback, and placement readiness verdict.
- `SESSION_INCOMPLETE`: Triggered when an interview is terminated early.
- `RECONNECTED`: State restoration for network drops.

## 🌐 REST API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |

## 🛠️ Configuration & Running

### Default Setup (Instant In-Memory H2 DB)
The service runs by default on port `8082` with an in-memory H2 database.

To run:
```powershell
$env:JAVA_HOME="C:\Program Files\Java\jdk-22"
.\mvnw.cmd spring-boot:run
```

H2 Console is accessible at: `http://localhost:8082/h2-console`
- JDBC URL: `jdbc:h2:mem:interviewdb`
- Username: `sa`
- Password: *(empty)*

### MySQL 8 Setup (Production Deployment)
To connect to MySQL 8 (SRS DB-1), configure the following in `application.properties`:
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/interview_db?createDatabaseIfNotExist=true&useSSL=false&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=root
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect
```

### AI LLM Configuration (Groq / Gemini / OpenAI)
Set your API key in your environment variables:
```powershell
$env:API_KEY="your_api_key_here"
```
If no key is configured, the service seamlessly falls back to the intelligent rule-based engine, ensuring 100% availability with zero downtime.
